# Amadeus Practice Terminal

Amadeus cryptic command প্র্যাকটিসের জন্য একটি অনানুষ্ঠানিক সিমুলেটর। শুধু HTML, JavaScript আর Tailwind দিয়ে তৈরি, একটি ফাইলেই পুরোটা।
লাইভ:https://iqbalhossainshuvo.github.io/Amadeus-Iqbal-Practice/
## চালানোর নিয়ম

`index.html` ফাইলটি ব্রাউজারে খুলুন। শুরু করতে `JI1234AB/SU` দিন।

GitHub Pages চালু করলে (Settings → Pages → Branch: `main`) অনলাইনেও খোলা যাবে।

## যা প্র্যাকটিস করা যায়

- সাইন ইন ও এনকোড/ডিকোড: `JI`, `JO`, `JD`, `DAC`, `DAN`, `DNA`, `DNE`, `DD`, `DO`
- অ্যাভেইলেবিলিটি: `AN`, `SN`, `AC`, `ACR`, `MD`/`MU`
- বুকিং: `SS`, `SB`, `NM` (ADT/CHD/INF), `AP`/`APE`/`APM`, `TK`, `RF`, `RM`/`RC`, `OS`
- SSR ও সিট: `SRDOCS`, `SR` (মিল, হুইলচেয়ার, FQTV…), `SM`, `ST`
- সেভ ও পরিবর্তন: `ET`/`ER`, `IG`/`IR`, `RT`, `RH`, `XE`, `XI`
- ভাড়া ও টিকেট: `FQD`, `FQN`, `FXX`, `FXP`, `FXB`, `FXA`, `TQT`, `TTE`, `FP`, `FM`, `FV`, `TTP`, `TWD`, `TWX`, `TRF`
- কিউ: `QP`, `QT`, `QS`, `QN`, `QI`

ভুল কমান্ড দিলে Amadeus-স্টাইল এরর মেসেজের সাথে বাংলায় কারণ ও সঠিক ফরম্যাট দেখায়। ডানদিকে ধাপে ধাপে লেসন, কমান্ড তালিকা, লাইভ PNR আর ভুলের খাতা আছে।
